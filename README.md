# StockLab — 개인 주식 분석·예측 플랫폼

한국투자증권 Open API(모의투자)로 시세와 투자자별 수급을 받고, 환율·미국 지수 같은 거시지표와
뉴스·공시를 합쳐 **관심종목 모니터링 → 외국인 매수 강도 스크리닝 → 5거래일 뒤 방향 예측**을 합니다.
배포하지 않고 **내 PC(Windows)에서만** 실행합니다.

> ⚠️ 이 프로그램은 **조회·분석 전용**입니다. 주문 기능이 없습니다.
> 예측은 통계적 참고치이며 투자 판단과 책임은 본인에게 있습니다.

### 1-2. 설치
1. 이 저장소를 내려받습니다 (예: `C:\stock-lab`)
   ```
   git clone https://github.com/<내 계정>/stock-lab.git C:\stock-lab
   ```
2. 폴더에서 **`setup.bat`** 더블클릭 → 패키지 설치 후 메모장으로 `.env` 가 열립니다.
3. `.env` 에 키를 붙여넣고 저장합니다.
   ```
   KIS_APP_KEY=발급받은키
   KIS_APP_SECRET=발급받은시크릿
   KIS_ENV=paper
   ```
4. **`check.bat`** 더블클릭 → 모두 `[OK]` 가 나오면 준비 끝.

> `.env` 는 비밀번호와 같습니다. `.gitignore` 에 들어 있어 GitHub 에 올라가지 않습니다.

### 1-3. 키 없이 먼저 구경하기
**`demo.bat`** 더블클릭 → 가상 데이터로 대시보드가 열립니다. 실제 데이터와 섞이지 않습니다.

### 1-4. "스마트 앱 컨트롤이 차단했습니다" 가 뜰 때

Windows 11 의 **스마트 앱 컨트롤(SAC)** 은 전자서명이 없거나 사용 기록이 적은 실행 파일·DLL 을 막습니다.
이 프로그램이 설치하는 파이썬 패키지 중 일부(계산용 DLL)가 대상이 될 수 있고, 인터넷에서 받은 ZIP 을
그대로 풀면 모든 파일에 '인터넷에서 받은 파일' 표시가 붙어 `.bat` 실행이 막히기도 합니다.

**① ZIP 차단 해제 후 다시 풀기** (가장 먼저)
1. 압축을 풀었던 `stock-lab` 폴더를 지웁니다.
2. 받은 ZIP 파일 **우클릭 → 속성 → 아래쪽 '차단 해제' 체크 → 확인**
3. 다시 압축을 풀고 `setup.bat` 실행

**② 설치 마지막 단계 `[3/3]` 진단 결과 보기**

`setup.bat` 이 끝에 패키지를 하나씩 불러와 보고 결과를 출력합니다 (나중에 `doctor.bat` 으로 다시 볼 수 있음).
```
스마트 앱 컨트롤  켜짐 (차단 중)
[OK]   pandas         2.3.1
[차단] lightgbm       DLL load failed ... [WinError 4551] 응용 프로그램 제어 정책에서 이 파일을 차단했습니다
```
- **`lightgbm` 만 [차단]** → 무시해도 됩니다. 예측 모델이 scikit-learn 엔진으로 자동 대체되고,
  시험 결과 성능 차이는 거의 없습니다(AUC 0.557 → 0.552).
- **필수 패키지(pandas·numpy·pyarrow·streamlit 등)가 [차단]** → 아래 ③ 또는 ④

**③ (권장) WSL — Windows 안의 리눅스에서 실행**

SAC 는 리눅스 프로그램에는 적용되지 않습니다. 대시보드는 Windows 브라우저에서 그대로 열립니다.
1. 시작 메뉴에서 **PowerShell 을 관리자 권한으로** 열고 `wsl --install` → 재부팅 → Ubuntu 사용자 이름·암호 설정
2. Ubuntu 창에서 (ZIP 을 `C:\stock-lab` 에 풀었다고 가정):
   ```bash
   sudo apt update && sudo apt install -y python3-venv
   cp -r /mnt/c/stock-lab ~/stock-lab && cd ~/stock-lab
   python3 -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt lightgbm
   python scripts/doctor.py
   cp .env.example .env && nano .env          # 키 입력 후 Ctrl+O, Enter, Ctrl+X
   python -m stocklab check
   python -m stocklab update
   streamlit run app/dashboard.py             # Windows 브라우저에서 http://localhost:8501
   ```
3. 매일 자동 실행(Windows 작업 스케줄러):
   ```
   schtasks /Create /TN "StockLab-Daily" /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 18:10 /F /TR "wsl -d Ubuntu -- bash -lc 'cd ~/stock-lab && .venv/bin/python -m stocklab update'"
   ```

**④ 스마트 앱 컨트롤 끄기** — 설정 → 개인 정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤 →
스마트 앱 컨트롤 설정 → 끄기.
⚠️ Windows 버전에 따라 **한 번 끄면 Windows 를 다시 설치하기 전에는 켤 수 없습니다.**
보안 기능을 영구히 잃을 수 있으므로 ③ 을 먼저 권합니다. 회사 PC 라면 IT 부서 정책을 따르세요.

## 2. 매일 쓰는 법

| 파일 | 하는 일 |
|---|---|
| `update.bat` | 수집 → 외국인·업종 수급 → 예측 → 카카오톡 저녁 요약 (**장 마감 후 하루 한 번**). 대시보드 사이드바의 **🔄 지금 업데이트** 와 같은 작업 |
| `realtime.bat` | **장중 실시간 시세** (평일 09:00~15:30, 창을 닫으면 멈춤) |
| `kakao_setup.bat` | 카카오톡 알림 처음 설정 (한 번) |
| `dashboard.bat` | 브라우저로 대시보드 열기 (http://localhost:8501) |
| `train.bat` | 모델 강제 재학습 (평소엔 update 가 7일마다 자동 재학습) |
| `doctor.bat` | 설치 상태 진단 (차단된 패키지 확인) |
| `mobile_setup.bat` | 휴대폰 접속용 방화벽 허용 (관리자 권한으로 한 번) |
| `schedule.bat` | 평일 **08:55 realtime**, **18:10 update** 자동 실행 등록 (PC 가 켜져 있어야 함) |

**첫 update 는 오래 걸립니다.** 시가총액 상위 300종목 × 3년치 일봉을 받느라 모의투자 기준 약 25분.
이후에는 매일 5분 정도입니다. 창에 `완료` 가 나올 때까지 닫지 마세요.

**대시보드에서 바로 업데이트**: 사이드바 **🔄 지금 업데이트** 를 누르면 `update.bat` 과 같은 작업이
보이지 않는 창에서 실행되고, 사이드바에 진행 막대(단계·n/300종목·경과 시간)와 '로그 보기'가 나옵니다.
그동안 대시보드는 계속 쓸 수 있고, 끝나면 화면이 새 데이터로 자동으로 바뀝니다.
- 대시보드 창을 새로고침하거나 닫아도 업데이트는 끝까지 진행됩니다 (기록: `logs\update_run.log`)
- `update.bat`·예약 작업(18:10)과 **동시에 실행되지 않습니다.** 하나가 실행 중이면 다른 쪽은
  "이미 업데이트가 실행 중" 으로 거절하고, 대시보드에는 '다른 곳에서 업데이트 실행 중' 이 표시됩니다
- 데모 모드와 휴대폰 보기 전용에서는 버튼이 나오지 않습니다 (비밀번호로 들어온 휴대폰은 사용 가능)
- 장중에 누르면 오늘 일봉은 잠정값으로 들어가고, 저녁 update 때 확정값으로 덮어씁니다

**18:10 인 이유**: 외국인·기관 수급은 장 마감 직후엔 잠정치입니다. 저녁에 받으면 확정치에 가깝고,
다음 날 update 때 최근 30일치를 다시 받아 덮어쓰므로 잠정치가 남지 않습니다.

## 3. 종목 설정

**관심종목은 대시보드에서 바로 추가·해제합니다.** 왼쪽 **종목 검색** → 종목 선택 → **☆ 관심종목 추가**.
시세 이력이 없는 종목이면 그 자리에서 한국투자증권으로 과거 시세·수급을 받고 예측까지 계산합니다(약 5~10초).

분석 범위 같은 고급 설정은 `config/settings.yaml`:

```yaml
watchlist:          # 항상 관심종목으로 표시 (대시보드에서 추가한 종목과 합쳐짐)
  "005930": 삼성전자

universe_auto:
  top_market_cap: 300   # 분석 대상 = 보통주 시가총액 상위 300 (자동, 매일 갱신)

picks:
  count: 30             # 관심종목 화면의 'AI 추천' 종목 수
  min_value_eok: 10     # 20일 평균 거래대금 10억원 미만은 추천 제외

universe:           # 자동 선정과 별개로 항상 분석할 종목
  "213420": 덕산네오룩스
```

- 종목코드는 **따옴표로 감싼 6자리**로 적습니다.
- `top_market_cap` 을 키우면 추천 후보가 넓어지지만 첫 수집 시간이 늘어납니다 (종목당 약 5초).

## 4. 대시보드 화면

**왼쪽 사이드바**
- **메뉴**: 관심종목 / 종목 상세 / 외국인 수급 / 예측 모델 / 거시지표
- **종목 검색**: KOSPI·KOSDAQ 전체 종목(약 2,700개)을 이름·코드로 검색 → 고르면 바로 상세 화면
- **전체 종목 시세**: 시장(KOSPI/KOSDAQ)·이름으로 거른 시가총액 순 표. 행을 누르면 상세 화면

| 페이지 | 내용 |
|---|---|
| **관심종목** | ① 내 관심종목 ② **시가총액 상위 20** ③ **AI 추천 30 — [1주 | 1개월] 탭** (강세 확률 상위 + 주요 근거 한 줄, 전날 추천에 없던 종목은 🆕, 모델의 과거 검증 성적 표시). 매일 update 후 갱신. 모든 표는 행을 누르면 상세로 이동 |
| **종목 상세** | 요약 카드(현재가·시가총액·강세 확률·52주 위치·외국인 5일·PER/PBR) → **왜 이렇게 예측했나** → 캔들·수급 차트 → 확률 추이 → 뉴스·공시. ☆ 관심종목 추가/해제 |
| **외국인 수급** | 분석 대상 300종목의 외국인 매수 강도 순위 |
| **예측 모델** | **추천 30 실제 성적 추적**(추천 종목 vs 전체 평균) + 과거 데이터 검증 + 중요 지표 |
| **업종 수급** | 업종별 외국인·기관 5/20일 순매수·수익률·평균 강세 확률 순위(행 클릭 → 그 업종 종목), 업종 × 20일 순매수 히트맵, 60일 누적 순매수 추이 |
| **거시지표** | 지수·환율 비교, 관심종목과 거시지표의 상관관계 |

- 색은 한국 관례대로 **상승 빨강 / 하락 파랑**입니다.
- **전체 종목 가격**: 공공데이터포털 키가 있으면 '전 거래일 종가'(공식), 없으면 네이버 당일 시세(비공식).
  분석 대상 300종목과 관심종목은 한국투자증권에서 받은 당일 종가로 표시됩니다.
- **AI 추천 필터**: 보통주만(우선주·스팩 제외), 20일 평균 거래대금 10억원 이상, 최신 시세가 있는 종목.
- **주요 근거 읽는 법**: "외국인 5일 순매수 비중 상위 4% ▲" = 분석 대상 중 외국인 순매수 비중이 상위 4% 이고,
  이것이 확률을 **올렸다(▲)**. ▼ 는 내린 요인. `[시장]` 은 모든 종목에 공통인 시장 요인입니다.

## 4-1. 장중 실시간 시세

장중에 **`realtime.bat`** 을 켜 두면 관심종목 + AI 추천 상위 15종목(최대 40종목)의 체결가를 실시간으로 받습니다.
- 관심종목 화면 맨 위 **📡 실시간 시세** 표가 5초마다 갱신, 종목 표의 현재가에도 반영(● 표시)
- 종목 상세에 **장중 1분봉** 차트(10초마다 갱신)
- 사이드바에 상태 표시: 🟢 실시간 연결 / 🟢 30초 조회 / ⚪ 꺼짐
- 한국투자증권 실시간(WebSocket) 연결이 5번 연속 실패하면 **30초마다 조회하는 방식으로 자동 전환**
- 장 시작 전에 켜면 09:00 까지 기다렸다 시작, 15:35 에 스스로 종료
- `schedule.bat` 으로 평일 08:55 자동 실행 가능

**무엇이 언제 바뀌나** (사이드바 **새로고침**은 저장된 값을 다시 읽을 뿐, 새 주가를 받아오지 않습니다)

| 화면 | 바뀌는 때 |
|---|---|
| 📡 실시간 시세 표 | `realtime.bat` 실행 중 **5초마다 자동** |
| 종목 상세 장중 1분봉 | `realtime.bat` 실행 중 **10초마다 자동** |
| 관심종목·시총 20·AI 추천 표의 현재가(● 표시) | `realtime.bat` 실행 중, **새로고침**하거나 화면을 누를 때 |
| 종목 상세 상단 현재가 | 실시간 값 → (없으면) 한국투자증권 현재가 조회(1분마다) → 전일 종가 |
| 전체 종목 시세·검색창 가격, AI 추천·확률, 수급, 업종 | `update.bat` 또는 사이드바 **🔄 지금 업데이트** (끝나면 화면 자동 갱신) |

`realtime.bat` 을 켜지 않았을 때는 사이드바 **💹 현재가 받기**(평일 09:00 이후)를 누르면
내 관심종목(최대 20)의 지금 가격을 한 번 받아 표에 반영합니다. 표 위 '가격 기준'에 몇 시 값인지 나옵니다.

## 4-2. 카카오톡 알림

**받는 알림** (`config/settings.yaml` 의 `alerts` 에서 켜고 끔)
- **저녁 요약** — update 가 끝나면 1회: AI 추천 상위 5, 관심종목 신호 변화(중립→강세 등), 외국인 순매수 상위 업종 3
- **장중 급등락** — realtime 실행 중 관심종목이 전일 대비 **±3%** 이상 (같은 종목·같은 방향은 1시간에 한 번)

**처음 설정 (10분, 한 번만)**
1. https://developers.kakao.com 로그인 → **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름 예: StockLab)
2. 만든 앱 → **앱 키** 에서 **REST API 키** 복사 → `.env` 의 `KAKAO_REST_API_KEY=` 뒤에 붙여넣기
3. **카카오 로그인** → 활성화 **ON** → **Redirect URI** 에 `http://localhost:8765/callback` 등록
4. **카카오 로그인 → 동의항목** → **카카오톡 메시지 전송(talk_message)** 을 '선택 동의'로 설정
5. **플랫폼 → Web** → 사이트 도메인에 `http://localhost:8501` 등록 (알림의 '대시보드 열기' 버튼용)
6. **`kakao_setup.bat`** 실행 → 브라우저에서 카카오 로그인·동의 → 카카오톡 **'나와의 채팅'** 에 테스트 메시지가 오면 완료

로그인은 약 2개월 유지되고, 매일 쓰면 자동 연장됩니다. 끊기면 `kakao_setup.bat` 을 다시 실행하세요.
알림이 실패해도 update·실시간은 멈추지 않습니다(`logs\stocklab.log` 에 사유 기록).

## 4-3. 휴대폰으로 보기 (집 밖에서도)

PC 에서 `dashboard.bat` 이 실행 중이면 휴대폰 브라우저로 같은 화면을 볼 수 있습니다.
집 밖(LTE·5G)에서는 **Tailscale**(무료 개인 VPN)로 연결합니다. 내 PC 와 내 휴대폰끼리만 연결되고
인터넷에 공개되지 않아 안전합니다.

**처음 설정 (15분, 한 번만)**
1. `.env` 에 휴대폰 접속용 비밀번호 입력: `DASHBOARD_PASSWORD=원하는비밀번호`
   (비워 두면 휴대폰에서는 **보기 전용** — 관심종목 추가·해제 불가)
2. **`mobile_setup.bat` 을 우클릭 → 관리자 권한으로 실행** (Windows 방화벽에서 8501 포트 허용)
3. **Tailscale 설치**
   - PC: https://tailscale.com/download → Windows 용 설치 → Google 등 계정으로 로그인
   - 휴대폰: 앱스토어/플레이스토어에서 **Tailscale** 설치 → **PC 와 같은 계정**으로 로그인 → 연결 켜기
4. `dashboard.bat` 실행 → PC 화면 왼쪽 사이드바 **📱 휴대폰으로 보기** 를 펼치면
   - **집 밖에서도 (Tailscale)** `http://100.x.x.x:8501` 과 QR 코드
   - **같은 와이파이에서** `http://192.168.x.x:8501` 과 QR 코드
5. 휴대폰 카메라로 QR 을 찍어 열고 비밀번호 입력
6. (추천) 휴대폰 브라우저 메뉴 → **홈 화면에 추가** → 앱처럼 바로 열기

**휴대폰 화면**
- 휴대폰에서 열면 자동으로 **간단히 보기**: 표는 종목·현재가·등락·강세 확률만, 요약 지표는 3칸 격자,
  메뉴는 화면 맨 위 버튼 줄. PC 에서도 사이드바 **📱 간단히 보기** 로 켜고 끌 수 있습니다.
- 카카오톡 알림의 '대시보드 열기' 버튼도 Tailscale 주소로 열립니다. 카카오 개발자 앱의
  **플랫폼 → Web → 사이트 도메인** 에 그 주소(`http://100.x.x.x:8501`)도 추가해 두세요.

**주의**
- PC 가 켜져 있고 `dashboard.bat` 이 실행 중이어야 합니다. **절전 모드**에 들어가면 접속이 끊기니
  설정 → 시스템 → 전원 → 절전을 '안 함'(또는 충분히 길게)으로 바꾸세요.
- 공유기 포트포워딩이나 공개 터널로 인터넷에 여는 방법은 권하지 않습니다(누구나 접속 시도 가능).

## 5. 예측 모델 — 무엇을, 어떻게

### 예측 대상
**1주(5거래일)·1개월(20거래일) 뒤 코스피 대비 초과수익이 날 확률** (`model.target: excess`, `model.horizons: [5, 20]`)

기간마다 모델이 따로 학습되고, 매일 update 때 각각 상위 30 종목을 추천합니다.
**1개월 예측은 1주보다 어렵습니다.** 기간이 길수록 그 사이 실적·뉴스·시장 변화가 많이 끼어들기 때문입니다.
가상 데이터 시험에서도 1개월 모델(AUC 0.525)이 1주 모델(0.572)보다 약했습니다.
그래서 추천 표마다 그 모델의 과거 검증 성적을 함께 보여주고, 약하면 ⚠️ 를 붙입니다.
실제 성적은 예측 모델 화면에서 기간을 골라 확인하세요 (1개월 추천은 20거래일이 지나야 첫 성적이 나옵니다).

주가 자체의 상승/하락(`absolute`)도 고를 수 있지만 권하지 않습니다. 개별 종목 등락의 상당 부분은
시장 전체가 움직여서 생기고, 시장 방향은 거의 동전 던지기라서 종목 고유의 신호(수급·뉴스)가 묻힙니다.
가상 데이터 실험에서도 absolute 는 기준선을 못 넘었고, excess 는 신호를 잡았습니다.

### 입력(특징값) — 모두 '그날 장 마감까지 알 수 있는 정보'만
| 분류 | 예 |
|---|---|
| 가격·거래량 | 1/5/20/60일 수익률, 이동평균 이격도, RSI, 변동성, 거래량 급증, 52주 고·저가 대비 |
| **수급** | 외국인·기관 순매수 / 거래량 (1·5·20일), 연속 순매수일, 외국인·기관 동반 매수 |
| 거시지표 | 코스피·코스닥, 원/달러, S&P500·나스닥·**필라델피아 반도체**, VIX, 미 10년물, 달러인덱스, WTI, 엔/달러 |
| 뉴스 | 최근 5일 기사 수, 평균 감성 점수 |
| 공시 | 최근 20일 호재성(수주·자사주 매입 등)/악재성(유상증자·CB 등) 공시 수 |

### 미래 정보가 섞이지 않게 한 장치
- 미국 지표는 **전날** 값만 씁니다 (미국 장은 한국 장 마감 뒤에 열림).
- 15:30 이후 뉴스, 모든 공시는 **다음 거래일**부터 반영합니다.
- 검증은 시간 순서대로(과거로 학습 → 다음 구간 평가) 하고, 사이에 5일을 비웁니다.
- `tests/test_pipeline.py` 가 "미래 데이터를 망가뜨려도 과거 특징값이 그대로인지" 검사합니다.

### 성적 읽는 법 (예측 모델 탭)
- **AUC**: 0.5 = 동전 던지기. 주식에서 **0.53~0.56** 이면 의미 있는 편, 0.6 을 넘으면 먼저 오류를 의심하세요.
- **상위 20% 평균수익 vs 하위 20%**: 모델이 강하게 본 종목이 실제로 더 올랐는지. 이 차이가
  **모든 검증 구간(fold)에서 꾸준히** 양수여야 쓸모 있습니다.

### 데이터가 쌓이면서 좋아지는 부분
| 데이터 | 처음 | 이후 |
|---|---|---|
| 주가 | 5년치 바로 확보 | — |
| 외국인·기관 수급 | **최근 약 30일** (KIS API 제공 범위) | 매일 1일씩 누적 |
| 뉴스 | 종목당 최근 100건 | 매일 누적 |
| 공시 | 1년치 | 매일 누적 |

수급·뉴스 이력이 짧은 동안에는 모델이 이 신호를 충분히 배우지 못합니다. 수집 시작 이전 기간은
0 이 아닌 '모름'으로 처리해 거짓 패턴을 배우지 않게 했습니다. **외국인 스크리너는 첫날부터 정상 동작합니다.**

## 7. 문제 해결

| 증상 | 원인·해결 |
|---|---|
| `EGW00133` | 토큰은 1분에 1번만 발급됩니다. 1분 뒤 다시 실행 (자동으로 한 번 기다렸다 재시도함) |
| `Read timed out` / `ReadTimeout` (openapivts.koreainvestment.com) | 모의투자 서버가 늦게 답한 것입니다. 자동으로 2·5·10초 쉬고 다시 시도하고, 그래도 안 되는 종목은 건너뛴 뒤 다음 update 때 다시 받습니다. 연속 15종목이 실패하면 서버 문제로 보고 수집을 멈추니 **잠시 후 `update.bat` 을 다시 실행**하세요 — 이미 받은 종목은 저장돼 있어 이어서 받습니다 |
| `EGW00201` | 초당 호출 초과. 자동 재시도됩니다. 계속되면 `stocklab/kis.py` 의 `MIN_INTERVAL` paper 값을 0.8 로 |
| "유효하지 않은 AppKey" 류의 오류 | `.env` 의 키, `KIS_ENV=paper`(모의투자 키) 확인. 키 앞뒤 공백 제거 |
| "스마트 앱 컨트롤" 차단 / `WinError 4551` | 위 **1-4** 참고. `doctor.bat` 으로 어떤 패키지가 막혔는지 확인 |
| 거시지표 일부가 비어 있음 | 야후 파이낸스(비공식)가 일시적으로 막힌 경우. 주요 지표는 FRED 로 자동 대체 |
| 대시보드 숫자가 안 바뀜 | 사이드바 **새로고침** (5분 캐시) |
| 뉴스·공시 탭이 비어 있음 | `.env` 에 네이버·DART 키 입력. 관심종목과 외국인 상위 종목만 수집됨 |
| check 에서 전체 종목 목록 `[실패]` / `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 공공데이터포털 키는 발급 후 **활성화까지 1~2시간** 걸리기도 합니다. `.env` 에 **Decoding(일반) 키**를 넣었는지 확인. 그동안은 네이버 시세로 자동 대체됩니다 |
| 관심종목 추가 후 차트가 안 나옴 | 그 자리에서 시세 받기에 실패한 경우(메시지에 사유 표시). 다음 `update.bat` 때 자동으로 받습니다 |
| `kakao_setup.bat` 에서 KOE006 / redirect_uri 오류 | 카카오 앱의 Redirect URI 가 정확히 `http://localhost:8765/callback` 인지 확인 |
| 카카오 테스트 메시지 실패 (-402, 권한 없음) | 동의항목에서 '카카오톡 메시지 전송' 을 켜고 `kakao_setup.bat` 다시 실행 |
| 사이드바가 계속 '⚪ 실시간 꺼짐' | `realtime.bat` 창의 메시지 확인. 장 시간(평일 09:00~15:30)에만 동작합니다 |
| 실시간이 '30초 조회' 로만 동작 | 실시간(WebSocket) 연결 실패 — 방화벽이 `ops.koreainvestment.com` 포트 31000(모의)/21000(실전)을 막는지 확인. 조회 방식으로도 기능은 같습니다 |
| 휴대폰에서 주소가 안 열림 | ① PC 에서 `dashboard.bat` 실행 중인지 ② `mobile_setup.bat` 을 **관리자 권한**으로 실행했는지 ③ 집 밖이면 휴대폰 Tailscale 이 '연결됨'인지 ④ PC 가 절전 모드가 아닌지 |
| 휴대폰에서 비밀번호 화면이 안 나오고 '보기 전용' | `.env` 에 `DASHBOARD_PASSWORD` 가 비어 있음. 입력 후 `dashboard.bat` 을 다시 실행 |
| `git pull` 뒤 `.env` 에 새 항목(예: `DASHBOARD_PASSWORD`)이 없음 | `.env` 는 비밀키 파일이라 GitHub 로 주고받지 않습니다. **`check.bat`** 을 실행하면(또는 update 때) 빠진 항목이 `.env` 맨 아래에 빈 값으로 자동 추가됩니다 |
| update 실행 시 "이미 업데이트가 실행 중입니다" | 대시보드의 🔄 지금 업데이트나 예약 작업이 돌고 있습니다. 끝난 뒤 다시 실행하세요. PC 를 강제로 껐다 켜서 남은 표시는 자동으로 무시됩니다 |
| 🔄 지금 업데이트 후 '지난 업데이트 실패' | 빨간 글씨에 사유가 나오고 '로그 보기'에 마지막 기록이 있습니다. 대부분 `check.bat` 으로 키·연결을 확인하면 해결됩니다 |
| 처음부터 다시 받고 싶음 | `data\market.sqlite` 삭제 후 update |

실행 기록은 `logs\stocklab.log` 에 남습니다. 문제가 생기면 이 파일 끝부분을 확인하세요.
